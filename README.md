🚗 Road Accident Dashboard (2021–2022)
📌 Project Overview

This project analyzes 307,972 road accident records (2021–2022).
I cleaned and processed the dataset in Excel, and then built an interactive  dashboard to generate insights.

The dashboard helps stakeholders such as the Ministry of Transport, Police, Emergency Services to understand accident patterns and improve road safety.

🧹 Data Cleaning & Processing

Removed duplicates and irrelevant fields.

Handled missing values (replaced with suitable values / removed where necessary).

Standardized data formats (dates, text, categories).


🎯 Business Requirements

Find total casualties and break down by severity (Fatal, Serious, Slight).

Identify casualties by vehicle type, road type, and road surface.

Compare accident trends between 2021 vs 2022.

Analyze casualties in urban vs rural areas.

Check effect of day vs night on accident numbers.

📊 Dashboard Preview

🔑 Key Insights

🚗 Cars account for ~79% of casualties → highest risk vehicle type.

🛣️ Single carriageway roads have the most accidents.

🌆 Urban areas (255k casualties) face more accidents than rural areas (162k).

🌞 Daytime accidents are almost 3 times higher than nighttime.

📈 2022 showed slightly higher casualties than 2021, meaning accidents are rising.

👥 Stakeholders & Use
